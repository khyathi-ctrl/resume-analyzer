# 🔍 Resume Analyzer

An AI-powered tool that compares your resume against a job description 
and gives you an ATS match score, matched skills, and missing skills.

## Features
- Upload PDF or DOCX resumes
- Paste any job description
- Get ATS match score (cosine similarity)
- See exactly which skills you have vs. what's missing

## Tech Stack
Python · Streamlit · scikit-learn · pypdf · python-docx

## How to Run
pip install -r requirements.txt
streamlit run app.py
